# Usama Ahmad

I build data pipelines, forecasting models and business intelligence systems for finance, retail and operations. My work covers the full process: understanding the business, bringing data sources together, checking the figures and building tools people use.

## Professional work

**Financial integration across nine-plus companies**

I built near-real-time Python pipelines combining ERP SQL data, APIs and SharePoint reports. I worked with finance teams on account mappings, currency conversion and reporting logic, and reconciled outputs against financial records. The resulting BI system supports financial reporting and comparisons across companies, periods and budgets.

**Retail analytics across 542 sites**

I integrated operational, ERP, file and audit data, resolved conflicting site records, and developed KPI calculations and manager scorecards for performance analysis.

**Fuel-stock forecasting**

I developed depletion models accounting for seasonal demand, holidays and fuel-price changes. These models guide replenishment planning and flag unusual depletion or purchasing patterns for investigation.

**Operational data systems**

I built structured data-capture workflows to replace fragmented manual records and provide reliable data for analysis.

My professional repositories are private. I can discuss my contributions and technical decisions without sharing confidential company code or data.
